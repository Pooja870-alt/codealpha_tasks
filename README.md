# codealpha_tasks
Breast Cancer Classification Using Machine Learning
Overview

A machine learning project for classifying breast cancer samples using the Wisconsin Diagnostic Breast Cancer dataset.

Models Used
Logistic Regression
Support Vector Machine (SVM)
Random Forest
XGBoost
Workflow
Load and explore the dataset
Split data into training and testing sets
Scale features where required
Train four ML models
Evaluate using Accuracy, Precision, Recall, F1-score, and ROC-AUC
Compare models and select the best-performing model
Perform sample prediction
Save the trained model using Joblib
Dataset
569 samples
30 numerical features
Classes: Malignant and Benign
Source: sklearn.datasets.load_breast_cancer
Technologies

Python | Pandas | NumPy | Scikit-learn | XGBoost | Matplotlib | Joblib | Google Colab

Note

This project is for educational purposes and is not intended for clinical diagnosis.
